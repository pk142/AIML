# 🤖 AI Resume Builder

An AI-powered resume optimization tool built with Streamlit and OpenAI APIs that helps tailor resumes according to specific job descriptions.

---

# 📌 Overview

AI Resume Builder analyzes job descriptions and generates optimized, ATS-friendly resume bullet points using OpenAI GPT models.

The application helps candidates customize their resumes quickly for different job applications while improving alignment with recruiter and ATS requirements.

---

# ✨ Features

- AI-generated resume bullet points
- Job description analysis
- ATS-friendly content generation
- Interactive Streamlit UI
- Real-time AI responses
- Resume text optimization
- Download-ready output
- Environment variable support using `.env`
